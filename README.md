# Project HELIX – Quality Engineering Portfolio

## Project Overview

Project HELIX is an eight-phase Quality Engineering Programme based on a simulated healthcare technology environment at GenomeBridge Clinical Systems Ltd.

The project demonstrates practical experience in software quality assurance, API testing, SQL database validation, automated regression testing, cross-browser testing, performance testing, CI/CD integration and quality reporting.

The programme was successfully completed across all eight phases, with practical testing activities, technical implementations and supporting quality engineering evidence.

**Project Type:** Professional Quality Engineering Simulation
**Role:** Quality Engineer
**Status:** Completed – All 8 Phases
**Environment:** Simulated Healthcare Technology System

## Technologies and Tools

* **Test Automation:** Playwright, Cypress, TypeScript
* **API Testing:** Postman, REST APIs, FHIR R4
* **Database Testing:** PostgreSQL, SQL, data integrity validation
* **CI/CD:** GitHub Actions, Git, GitHub
* **Testing Practices:** Functional testing, regression testing, integration testing, cross-browser testing and performance testing
* **Quality Engineering:** Risk-based testing, defect investigation, test evidence, quality reporting and release readiness assessment

## Quality Engineering Activities

### 1. Test Strategy and Risk Assessment

Applied structured quality engineering practices to assess software risks, identify testing priorities and develop appropriate testing approaches.

### 2. API Testing and Validation

Performed REST API testing using Postman, including FHIR R4 resource validation, response verification and checks of relationships between healthcare resources.

### 3. SQL and Data Quality Validation

Developed SQL queries to investigate data quality issues, verify data integrity and identify inconsistencies affecting operational processes.

Produced data quality reports and supporting validation evidence.

### 4. Automated Regression Testing – Cypress

Implemented Cypress automated tests to validate application functionality and support repeatable regression testing.

### 5. Cross-Browser Automation – Playwright

Developed Playwright and TypeScript automated tests to support functional validation across browser environments.

### 6. CI/CD and Performance Testing

Implemented GitHub Actions workflows to support automated quality checks and performance testing activities.

### 7. Quality Reporting and Governance

Produced quality metrics, testing evidence and reporting artefacts to support test assessment, defect investigation and quality-related decisions.
